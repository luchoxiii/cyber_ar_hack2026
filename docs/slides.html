CONTROL Y RESILIENCIA // 4 GUARDRAILS DETERMINISTAS OWASP

Seguridad Defensiva y Contención de Riesgos

“No permitimos que el modelo ejecute comandos libres: 4 barreras matemáticas”

1. Aislamiento Semántico (Anti-LLM01)

Logs crudos confinados en <raw_logs>. Neutraliza inyecciones indirectas en User-Agents, nombres de usuario o payloads HTTP maliciosos.

2. Salida Estructurada Tipada (Anti-LLM02)

Validación estricta contra JSON Schema predefinido. Prohíbe la emisión de sintaxis shell o campos no autorizados (ej. execute_command).

3. Whitelist de Infraestructura (Anti-DoS)

Módulo Python determinista sin IA. Intercepta e impide bloquear gateways (192.168.1.1), DNS corporativo o redes de comando (10.0.0.0/8).

4. Comando Parametrizado (Anti-LLM08)

El backend ensambla la regla fija (ufw insert 1 deny from {ip} to any) sin invocar shell=True ni scripts arbitrarios.
